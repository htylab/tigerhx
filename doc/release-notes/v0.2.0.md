## TigerHx v0.2.0: the previous GUI's workflows, a friendlier GUI

**Download (Windows):** unzip and run `tigerhxgui.exe`; nothing to install. The window uses the Microsoft Edge WebView2 runtime, which Windows 10/11 normally already has.
- `tigerhxgui-v0.2.0.zip`: the GUI. Models are downloaded on first use.
- `tigerhxgui-rust-v0.2.0.zip`: the same GUI as a single native executable. The default model (`cine4d_v0006`) is built in, so it segments without a download; the other models are downloaded on first use.

### The previous GUI's workflows
- **Case lists (CSV)** with `Filename, Apex, mat_in_inputdir, nii_in_inputdir` can be added with “＋ Files / CSV”: a filled-in Apex counts as confirmed, and each row's two columns override the output settings for that case. Files that do not exist are listed in the Log.
- **GenCSV** (“Only write a CSV” in the folder dialog) lists the NIfTI files of a folder in such a CSV, with the Apex column left blank to fill in.
- **Open results (.mat)** opens a folder of `*pred*.mat` files of this or the previous GUI, read-only; the apex is taken from their 6/4 sectors.
- All `.mat` files go to one output folder (`<workspace>/output` or the folder set in Settings), named as before.
- Overlays: the previous GUI's **6/4 sectors** next to AHA 17 (both are in the `.mat`), the **LV** or **RV** mask alone, and a **viridis** colour map.
- **Log** panel, and **Download all models** in Settings for computers that are usually offline.

### Friendlier GUI
- Add, Settings and Shortcuts open as dialogs; the case list shows name, folder, apex and warnings, with filters (to confirm, flagged, done, …).
- A slice bar shows every slice coloured by level (basal, mid, apical, apex cap) with the first apical slice and flagged slices marked; click a slice to show it.
- “✓ Confirm, next →” confirms the apex and moves on to the next case to confirm.
- Keyboard: ← → frame, ↑ ↓ slice, Space play, **A** use the current slice as apex, **Enter** confirm, **N / P** next / previous case, **M** all slices, **O** next overlay, **?** list.

### Fixes
- Adding files failed (the file dialog did not open), and file and folder dialogs could hang the window.
- Adding a large folder no longer freezes the GUI while it is scanned.
- In windows 1000–1100 px wide the status bar (Log) could not be clicked.
- Enter did nothing after the Segment button had been clicked.

The Windows builds are now tested in their real window on every change: adding files, folders and CSVs through the Windows dialogs, segmenting, confirming, settings, opening results and closing.

For research use only; not for clinical use.
