## TigerHx v0.1.0: new segmentation GUI

**Download (Windows):** `tigerhxgui-v0.1.0.zip`. Unzip and run `tigerhxgui.exe`; nothing to install. Models are downloaded on first use. The window uses the Microsoft Edge WebView2 runtime, which Windows 10/11 normally already has.

### New GUI (tigerhxgui)
- Add cine NIfTI files or whole folders directly; no CSV needed. Segmentation runs in a background queue.
- Review in the NiiVue viewer: single slice or all slices, zoom to the heart or full image, cine playback.
- Overlays: segmentation, smooth contours (LV endocardium, LV epicardium, RV) and AHA 17. AHA segments are coloured by wall and numbered.
- Apex and slice order are suggested automatically; confirm them on the images and the AHA map updates at once.
- Segmentation check: lists slices worth a look (a cavity larger at ES than at ED, a missed slice, a basal LV not enclosed by myocardium) and jumps to each one.
- Same outputs as before: `seg.nii.gz`, `aha17.nii.gz` and the `.mat` file of the previous GUI (`*_pred_<version>.mat`).
- Executable is about 53 MB, down from 87 MB.

### Also
- Fixes in the command-line tool and the previous Tk GUI (`tigercinegui-v0.1.0.zip`).
- Shared core module with tests.
- `tools/eval_acdc.py` validates models against expert ACDC labels.

For research use only; not for clinical use.
